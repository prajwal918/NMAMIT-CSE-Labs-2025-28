# Experiment 10: Distance Vector Routing Algorithm

**Aim.** Write a program in C for the distance vector routing algorithm to find a suitable path for transmission, and display the routing table of every router.

## Files
| File | Purpose |
|---|---|
| `exp10.c` | Implements Distance Vector routing using the Bellman-Ford equation |

## How to Run

Compile and run using GCC:
```bash
gcc exp10.c -o exp10
./exp10
```
